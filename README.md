# maxwells-detection-jacket
This project presents a wearable electromagnetic field detection device designed to make Maxwell’s four equations visually observable. The broader goal of the device is to demonstrate that the electromagnetic phenomena described by Maxwell are not abstract mathematical concepts but active physical forces present in everyday environments.
